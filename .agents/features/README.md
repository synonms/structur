# Features

This folder contains feature-specific prompt files used to initiate implementation of particular features in the Sample projects.

## Structure

Each feature has its own subfolder named after the feature (pluralised, PascalCase), for example `employments/`. Each subfolder contains:
- `[feature-name].prompt.md` - A pre-populated prompt template for implementing the feature, based on the reusable template in `prompts/new-feature.prompt.md`

## Historical Artefacts

Implementation summary files (e.g. `EMPLOYMENT_FEATURE_IMPLEMENTATION.md`) are historical records generated during previous implementation runs. They are kept here for reference but are not part of the active agent system and do not need to be maintained.
